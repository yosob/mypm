# 看板对标调研与升级方案（DASHBOARD.md）

> 结论先行：当前看板只有「甘特图 + 任务清单 + 资料面板」，对标飞书多维表格 PM 模板 / Linear / Asana 后，最值得补的是：**多视图（看板/日历）、任务详情、统计图表、筛选排序搜索、进度可视化**。分三档列出，建议做「快速加强版」。

## 一、同类产品看板功能盘点

### 飞书多维表格 PM 模板（最直接的参照）

核心哲学："**数据一份，多种视图**"（[视图总览](https://www.feishu.cn/hc/zh-CN/articles/360049067931)）：

| 视图 | 对 PM 的用途 |
|---|---|
| 表格视图 | 结构化全量数据、批量编辑、字段筛选排序 |
| 看板视图 | 按**状态**分组卡片，**拖拽改状态**（todo/doing/done 流转） |
| 日历视图 | 按月看排期，一眼看清某周密集度 |
| 甘特视图 | 时间进度 + **任务依赖线** + 今日线（[甘特视图](https://www.feishu.cn/hc/zh-CN/articles/558830919244)） |
| 画册视图 | 卡片式资料陈列 |
| 表单视图 | 收集信息（我们不需） |

[官方 PM 模板](https://www.feishu.cn/hc/zh-CN/articles/184008024837)的组合套路：**表格（录入）+ 甘特（排期）+ 看板（流转）+ 仪表盘（统计）** 四件套。

**仪表盘**（[文档](https://www.feishu.cn/hc/zh-CN/articles/161059314076)）：柱状/条形/折线/组合图，统计维度如：任务完成率、各状态数量、按项目分布、按负责人分布。

### Linear（Home/My Issues 模式）

- **聚合首页**：所有项目的任务一屏汇总（[Linear](https://linear.app/)）
- **日期驱动的分组**：Overdue / Due today / This week / Later 分组展示
- **逾期可视化**：日期图标**变红**（[due dates](https://linear.app/docs/due-dates)），hover 显示剩几天
- 保存的自定义视图（过滤器组合）

### Asana（My Tasks / Dashboard 模式）

- My Tasks 按 **Recently assigned / Today / Upcoming / Overdue** 分区（[帮助中心](https://help.asana.com/s/article/managing-projects)）
- 仪表盘组件：**完成率数字卡、逾期数、即将到期数**（[Bold BI 示例](https://www.boldbi.com/dashboard-examples/information-technology/asana-project-management-dashboard/)）
- 高级搜索 + 保存搜索

### 通用模式总结（各家都有）

1. 多视图切换（表格/看板/甘特/日历）
2. 任务详情侧栏（点开看描述、截止、历史、资料）
3. 状态流转拖拽（看板列间拖动）
4. 统计图表（完成率、状态分布、逾期趋势）
5. 筛选/排序/搜索
6. 进度可视化（项目完成百分比条）
7. 日期红黄绿预警（逾期红、临近黄）

## 二、我们现状的差距

| 能力 | 现状 | 差距 |
|---|---|---|
| 甘特图 | ✅ 有（Day/Week/Month/Year、里程碑◆、今日线） | 无依赖线（数据模型有 depends_on 列但没用上）；不能拖拽改期 |
| 任务清单 | ✅ 有勾选完成 | 无状态列（todo/doing）、无搜索、无排序、点不开详情 |
| 看板视图 | ❌ 无 | status 字段建了没用 |
| 日历视图 | ❌ 无 | — |
| 任务详情 | ❌ 无 | 描述、历史摘要、资料都看不到（只在 Lark 问 AI 才有） |
| 统计图表 | ❌ 只有三个数字卡 | 无完成率、状态分布图 |
| 筛选 | 只有项目下拉 | 无状态/日期范围/关键词 |
| 进度可视化 | ❌ 无 | — |

## 三、升级方案（三档）

### 第一档：快速加强（纯前端，1 次改动，推荐先做）

1. **任务详情侧栏**：点任务弹出——描述、截止、状态、所属项目历史摘要、资料链接（数据 API 已全有，纯前端）
2. **筛选/排序/搜索**：状态下拉（todo/doing/done/全部）、关键词搜索框、按截止日/创建日排序
3. **日期预警色**：清单里逾期红、3 天内黄（甘特条同步变色）
4. **项目进度条**：项目卡片显示 `完成 n/m` 百分比条
5. **统计条**：顶部加一个简单状态分布条形图（原生 CSS/SVG，不引图表库）

### 第二档：多视图（加两个视图）

6. **看板视图**：按 status 分三列（待办/进行中/已完成），卡片可拖拽改状态（调现有 update API + 新增 status patch）
7. **日历视图**：月历格子里显示当日到期任务点，点击跳详情（自绘月历，无依赖）

### 第三档：进阶（需要后端/数据配合）

8. 完成率/逾期趋势折线图（引 Chart.js）
9. 甘特图拖拽改期（写回 due_date）
10. 依赖线渲染（启用 depends_on）
11. 周报视图：按周聚合 history 摘要（配合 AI 生成周报）
12. 深色模式 / 移动端适配

## 四、实施建议

- 第一档全部纯前端改动（index.html + 现有 API），风险零，收益最大
- 第二档的看板需要 `update_task` 支持 status 参数（一行 schema 改动）+ 拖拽交互
- 第三档按需再做，折线图和周报可以等数据积累几周后更有意义
