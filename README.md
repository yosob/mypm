# mypm — 你的 AI 项目经理

> 一个跑在自己电脑上的 AI 项目管理助手：**你在 Lark 里跟它聊天，它替你管项目、记任务、盯截止日、到点提醒你**。不用装 App、不要公网服务器，数据全在自己手里。

## 这是什么？

想象你有一个从不遗漏的秘书：

- 开完会，把**会议纪要直接粘给它**（Lark 私聊或群里 @它）→ 它自动提取出待办、截止日、里程碑、提到的微信群和文档链接 → 列一张清单等你过目 → 你回一句「确认」就归档入库
- 早上 9 点，它主动私聊你：**「这周有 3 件事到期，1 件已逾期」**
- 随时问它：「**今天我该干嘛**」「XX 项目进展如何」「把那个评审推迟到下周三」「这件事的对接群叫什么来着」——自然语言，直接执行
- 想看全局？打开本地网页**甘特图看板**，项目排期一目了然

与 Notion/飞书项目/Asana 的本质区别：那些工具需要**你去填表**；mypm 是 **AI 原生**的——录入靠对话，整理靠 AI，你只做确认和决策。所有数据操作都必须经过 AI 的 11 个受控工具（两段式确认入库，防幻觉），而非让模型自由改库。

## 核心功能

**对话（Lark 私聊/群@，主入口）**
- 📥 纪要秒变任务：待办、排期（开始~截止）、优先级 P0-P3、里程碑、微信群/链接资料、项目进展摘要，一次提取、确认后入库
- 💬 自然语言查询与操作：查今日/本周/逾期，改期、置状态、记群名、设自定义字段（如负责人）
- ⏰ 主动提醒：每天 9:00 机器人私聊推送（进入 7 天窗口一次 + 逾期当天一次，不重复轰炸）

**看板（http://127.0.0.1:8787，本地网页）**
- 📈 甘特图（dhtmlx，项目分组树/里程碑/今日红线/逾期预警色）
- 📋 任务列表（筛选/搜索/排序，7 列信息）与 🗂 看板（拖拽流转状态）
- 多项目进度条、状态分布图；任务/项目全字段手动编辑（居中弹窗）
- 资料（微信群/链接）项目级+任务级两层管理；⚙ 自定义字段随心扩展

**数据与安全**
- 单文件 SQLite，本地存储，每日自动备份（保留 14 份，损坏自动恢复）
- AI 只能经工具读写、且删除仅限看板手动操作（防误删）；纪要入库需你确认

## 它长什么样

```
你(Lark) ───聊天───▶ AI 经理(pi agent + glm-4.7，11个工具)
                        │ 读/写
                        ▼
                   SQLite 项目库 ◀── 手动编辑 ── 网页看板(甘特/列表/看板)
                        │
             每天9:00 ──▶ 机器人私聊提醒卡片
```

技术栈：TypeScript · pi agent（agent 循环）· 智谱 GLM · Lark WebSocket · SQLite · Hono + dhtmlx（前端零构建）

## 快速开始

```bash
# 0) 准备：Node ≥22、一个 Lark 自建应用（机器人+长连接）、GLM API Key
# 1) 配置：复制 config.example.json 为 config.json，填入密钥（见下方"配置说明"）
cd app && npm install
npm run dev        # 启动；或 Windows 双击项目根 start-mypm.bat
```

- 看板：http://127.0.0.1:8787 ｜ Lark：私聊机器人说句"你好"（首次私聊会记住你，用于提醒推送）
- 日志 `logs/`，备份 `backups/`，数据 `app/data/mypm.db`

## 配置说明（config.json）

唯一配置文件，在项目根目录（**已被 gitignore，含密钥勿提交**；模板见 `config.example.json`）。
任何密钥字段的值都可以直接写明文，或写 `"$环境变量名"` 引用（`$$` 转义字面美元符；引用的变量未定义时该值为空并在日志警告）——本地单人明文省事，部署/开源时全部 env 化。改完重启生效。

### llm —— 用哪个 AI 模型

所有模型厂家都在 `providers[]` 里平等声明（智谱也只是其中一家，无任何特殊处理）；顶层 `provider` + `model` 两个字段决定当前用哪家哪个模型。

**顶层字段**

| 字段 | 默认 | 说明 |
|---|---|---|
| `provider` | `zhipu` | 当前使用的厂家 id（必须对应 providers[] 里某项的 id） |
| `model` | `glm-4.7` | 模型 id；填错启动时会列出全部可用模型再退出 |

**providers[] 每项（一个厂家一个对象，想接几家写几家）**

| 字段 | 说明 |
|---|---|
| `id` | 厂家标识，provider 字段填它 |
| `name` | 显示名（可省略） |
| `baseUrl` | API 端点，如 `https://open.bigmodel.cn/api/coding/paas/v4` |
| `api` | 协议：`openai-completions`（智谱/DeepSeek/Kimi/Qwen/中转站等绝大多数）或 `anthropic-messages`（Claude 协议端点） |
| `apiKey` | 该厂家的密钥（支持 `$ENV` 引用） |
| `models[]` | 模型清单：`id`（必填）、`name`、`contextWindow`(默认128k)、`maxTokens`(默认8192) |

**切换模型**：`provider` 改成另一家的 id、`model` 改成它 models 里的 id，重启即换（如 `deepseek` + `deepseek-chat`）。新增厂家 = providers[] 抄一段改 baseUrl/key/models。

模板 `config.example.json` 已内置 10 家主流厂商可直接抄用：智谱（双端点）、DeepSeek、Kimi、通义千问、OpenAI、Claude、硅基流动、OpenRouter、Ollama 本地。

### lark —— Lark/飞书 应用机器人

| 字段 | 说明 |
|---|---|
| `appId` / `appSecret` | 自建应用凭证（开放平台 → 凭证与基础信息） |
| `domain` | `lark`（国际版）或 `feishu`（国内飞书） |

### notify —— 提醒备用通道

| 字段 | 说明 |
|---|---|
| `webhook` | 群自定义机器人 Webhook（机器人私聊失败时的兜底；可留空） |

### app —— 行为参数

| 字段 | 默认 | 说明 |
|---|---|---|
| `port` | `8787` | 看板端口 |
| `remindDays` | `7` | 提前 N 天进入提醒窗口 |
| `remindCron` | `0 9 * * *` | 每日提醒时刻（cron 表达式，默认每天 9:00） |
| `sessionMax` | `200` | 会话原始消息条数上限，超过触发压缩 |
| `sessionKeep` | `50` | 压缩后保留的最近消息条数（其余并入 AI 滚动摘要） |
