# mypm — 你的 AI 项目经理

> 一个跑在自己电脑上的 AI 项目管理助手：**你在 Lark 里跟它聊天，它替你管项目、记任务、盯截止日、到点提醒你**。不用装 App、不要公网服务器，数据全在自己手里。

## 这是什么？

想象你有一个从不遗漏的秘书：

- 开完会，把**会议纪要直接粘给它**（Lark 私聊或群里 @它）→ 它自动提取出待办、截止日、里程碑、提到的微信群和文档链接 → 列一张清单等你过目 → 你回一句「确认」就归档入库
- 早上 9 点，它主动私聊你：**「这周有 3 件事到期，1 件已逾期」**
- 随时问它：「**今天我该干嘛**」「XX 项目进展如何」「把那个评审推迟到下周三」「这件事的对接群叫什么来着」——自然语言，直接执行
- 想看全局？打开本地网页**甘特图看板**，项目排期一目了然

与 Notion/飞书项目/Asana 的本质区别：那些工具需要**你去填表**；mypm 是 **AI 原生**的——录入靠对话，整理靠 AI，你只做确认和决策。所有数据操作都必须经过 AI 的 11 个受控工具（两段式确认入库，防幻觉），而非让模型自由改库。

## 核心功能

**对话（Lark 私聊/群@，主入口）**
- 📥 纪要秒变任务：待办、排期（开始~截止）、优先级 P0-P3、里程碑、微信群/链接资料、项目进展摘要，一次提取、确认后入库
- 💬 自然语言查询与操作：查今日/本周/逾期，改期、置状态、记群名、设自定义字段（如负责人）
- ⏰ 主动提醒：每天 9:00 机器人私聊推送（进入 7 天窗口一次 + 逾期当天一次，不重复轰炸）

**看板（http://127.0.0.1:8787，本地网页）**
- 📈 甘特图（dhtmlx，项目分组树/里程碑/今日红线/逾期预警色）
- 📋 任务列表（筛选/搜索/排序，7 列信息）与 🗂 看板（拖拽流转状态）
- 多项目进度条、状态分布图；任务/项目全字段手动编辑（居中弹窗）
- 资料（微信群/链接）项目级+任务级两层管理；⚙ 自定义字段随心扩展

**数据与安全**
- 单文件 SQLite，本地存储，每日自动备份（保留 14 份，损坏自动恢复）
- AI 只能经工具读写、且删除仅限看板手动操作（防误删）；纪要入库需你确认

## 它长什么样

```
你(Lark) ───聊天───▶ AI 经理(pi agent + glm-4.7，11个工具)
                        │ 读/写
                        ▼
                   SQLite 项目库 ◀── 手动编辑 ── 网页看板(甘特/列表/看板)
                        │
             每天9:00 ──▶ 机器人私聊提醒卡片
```

技术栈：TypeScript · pi agent（agent 循环）· 智谱 GLM · Lark WebSocket · SQLite · Hono + dhtmlx（前端零构建）

## 快速开始

```bash
# 0) 准备：Node ≥22、一个 Lark 自建应用（机器人+长连接）、GLM API Key
# 1) 配置：按 .env.example 填 .env（GLM/Lark 凭证）
cd app && npm install
npm run dev        # 启动；或 Windows 双击项目根 start-mypm.bat
```

- 看板：http://127.0.0.1:8787 ｜ Lark：私聊机器人说句"你好"（首次私聊会记住你，用于提醒推送）
- 日志 `logs/`，备份 `backups/`，数据 `app/data/mypm.db`

## 边界与二期

- 个人单用户设计（不做多人协作）；删除操作仅限看板（AI 永不删除）
- 二期候选：图片纪要（GLM vision）、重复任务、日历视图、周报生成、内网穿透远程看板、微信推送
